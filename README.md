# Models of Computation

Implementación en C++ de modelos formales de computación: Autómata Finito (FA), Autómata de Pila (PDA), Máquina de Turing (TM), Autómata Linealmente Acotado (LBA) y Gramática Libre de Contexto (CFG).

## Tecnologías

- C++

## Compilación y ejecución

```bash
bash build.sh
./mainPDA   # Para el autómata de pila
./mainTM    # Para la máquina de Turing
```

## Estructura

```
include/
  FA/   # Autómata Finito
  PDA/  # Autómata de Pila
  TM/   # Máquina de Turing
  LBA/  # Autómata Linealmente Acotado
  CFG/  # Gramática Libre de Contexto
```
